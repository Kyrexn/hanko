segurança

Selado no seu aparelho.
Só você abre.

Mesmo que alguém invadisse o servidor, encontraria só blocos cifrados. Sem a sua senha mestra — que só existe na sua cabeça — eles não servem para nada.

Esqueceu a senha mestra? O Kit de Emergência traz uma chave de recuperação que só você guarda. É o único jeito de voltar — por isso nem nós conseguimos.

  1. 一Senha mestrafica só com você
  2. 二Argon2id · 64 MiBtransforma a senha numa chave cara de adivinhar
  3. 三AES-256-GCMcifra cada senha, código e documento
  4. 四Sincroniao servidor recebe só o bloco cifrado

Chrome e Edge

Extensão de preenchimento

Como instalar carregando…
Prefere o .zip?

Baixe o pacote da extensão, extraia e use Carregar sem compactação. Pelo app do Windows ela se atualiza sozinha; pelo .zip, não.

Extensão em 3 passos (e nunca mais)

  1. Instale o Hanko no Windows e abra Ajustes → Extensão → Preparar pasta.
  2. Clique em Abrir no Chrome (ou no Edge) e ligue o Modo do desenvolvedor.
  3. Carregar sem compactação → escolha a pasta mostrada no app. Pronto: cada atualização do Hanko atualiza a extensão sozinha.
perguntas

Perguntas frequentes

É grátis mesmo? Qual é a pegadinha?

Não há pegadinha: sem anúncios, sem plano pago, sem venda de dados. O código é aberto (GPL-3.0) — qualquer pessoa pode conferir o que ele faz.

Vocês conseguem ver minhas senhas?

Não. O cofre é cifrado no seu aparelho com uma chave que só a sua senha mestra abre. O servidor guarda apenas o bloco cifrado.

E se eu esquecer a senha mestra?

Use a chave do Kit de Emergência, criada no cadastro (ou em Ajustes). Sem a senha mestra e sem o kit, ninguém consegue abrir o cofre — nem nós.

Funciona sem internet?

Sim. O cofre fica no aparelho; a internet só é usada para sincronizar com os outros aparelhos e para ícones opcionais dos sites.

Consigo trazer minhas senhas de outro lugar?

Sim: Chrome, Edge, Bitwarden, 1Password, LastPass (CSV/JSON) e os códigos do Google Authenticator (QR de exportação). Fica em Ajustes → Dados e backup.

Preciso criar conta?

Não. Sem conta, o Hanko funciona só naquele aparelho. A conta serve para sincronizar Windows, Android e a extensão.
